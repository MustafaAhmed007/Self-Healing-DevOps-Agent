# Security Policy

## Scope

Security issues include sandbox escapes, unauthorized network access, secret exposure, unsafe tool authorization, dependency abuse and prompt-injection paths that cross the content/authority boundary.

## Reporting

Please report vulnerabilities privately to the repository owner before opening a public issue. Include reproduction steps, affected component, impact and a minimal proof where safe.

Do not include real credentials or sensitive personal data in reports.

## Security baseline

The project is experimental. Do not run untrusted repositories against infrastructure that contains production credentials. Use an isolated host for high-risk evaluation.
